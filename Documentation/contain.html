Container Classes

The Container Classes are the structural backbone of a SimpleSprite application. They form a containment hierarchy: an SS_Game owns a stack of SS_World objects, each world owns a collection of SS_Layer objects, and each layer owns a list of SS_LayerItem objects.

This hierarchy provides a clean separation of concerns:

SS_GameThe top-level application controller. Owns the window, OpenGL context, trig tables, and a world stack.
SS_WorldA self-contained game mode or level. Manages layers, input polling, the process/render loop, collision detection, and world-level state such as zoom and scroll position.
SS_LayerA z-ordered group of items with its own offset, scale, and tint. Layers can scroll with the world, stay fixed for HUDs, be paused, hidden, or reordered.

Together these three classes provide the scaffolding on which all sprites, frames, text, tiles, particles, and GUI widgets are placed. You typically subclass SS_Game to provide your Run method, create one or more SS_World subclasses for each game mode, and add SS_Layer instances to organize your content.

Constructors

Each container class has a constructor that initializes its internal state:

SS_Game()
SS_World()
SS_Layer(Uint32 flags=SS_NONE)
SS_Layer(SS_World *world, Uint32 flags=SS_NONE)

SS_Game creates the window and OpenGL context. SS_World starts as an empty container awaiting layers. SS_Layer can be created standalone or attached to a world at construction time.

SS_Game::Run

virtual void Run() = 0

Main entry point for the game. Subclasses must implement this method. The Run method typically contains setup code, pushes an initial world onto the stack, and enters the main loop. See SS_Game::Run for details.

SS_Game::PushWorld

void PushWorld(SS_World *w)

Push a world onto the world stack and make it active. Use this to transition between game modes (menu, gameplay, pause) without destroying the previous world. See SS_Game::PushWorld.

SS_World::NewLayer

SS_Layer* NewLayer(Uint32 f=SS_NONE)

Create a new layer owned by this world. The optional flags parameter controls scroll and zoom behavior. See SS_World::NewLayer.

SS_Layer::AddItem

void AddItem(SS_LayerItem *item)

Add an item to the layer. The item becomes a child of the layer and will be processed and rendered with it. See SS_Layer::AddItem.
