SS_Sound.h

SS_Sound

SS_Sound wraps a single decoded sound sample. Internally it uses SDL3_mixer's MIX_Audio/MIX_Track model; the old Mix_Chunk API no longer exists in SDL3_mixer. SS_Sound preserves the classic channel-number interface, but playback now routes through MIX_Track voices.
