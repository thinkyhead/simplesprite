SS_Game.h

SS_Game

SS_Game represents the base application class. Your game should subclass SS_Game overriding the Run method. The Run method will contain your setup code and main loop.

You must then edit the main.cpp file, replacing all instances of Demo_Game with the name of your own SS_Game subclass.

Constructors

SS_Game()

When the base game class is instantiated it creates a window based on your settings in the SS_Config.h file, initializes the audio system via SDL3_mixer, and generates sine and cosine tables for use in game calculations.

If your game needs to maintain its own game-wide data it should override the Init method and do its allocation and initialization there.

InitScreen

void InitScreen()

Create the window and OpenGL context, then set the default GL state for 2D rendering. On modern SDL the path is SDL_CreateWindow + SDL_GL_CreateContext; GL_LIGHTING is disabled and GL_TEXTURE_ENV_MODE is set to GL_MODULATE so textured sprites render with correct alpha.
