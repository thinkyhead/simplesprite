SS_GUI.h

SS_Scrollbar

Superclass: SS_Gadget

A scrollbar gadget that combines a track (SS_SlideArea) with a draggable thumb and optional scroll buttons, providing a complete scrolling interface for content that exceeds the visible area.

Member Data

SS_SlideArea*trackThe track area that constrains thumb movement
SS_Sprite*thumbSpriteThe draggable thumb sprite
SS_Sprite*upButtonOptional scroll-up button sprite
SS_Sprite*downButtonOptional scroll-down button sprite
floatminVal, maxValThe scrollable value range
floatvalueThe current scroll position
floatpageSizeThe size of the visible page (for thumb sizing)
boolisVerticalFlag to orient the scrollbar vertically

Constructors

SS_Scrollbar(
    SS_GUI *gui,        // The GUI that gets the scrollbar
    float x,            // X coordinate of the scrollbar
    float y,            // Y coordinate of the scrollbar
    float length,       // Length of the scrollbar track
    float minVal,       // Minimum scroll value
    float maxVal,       // Maximum scroll value
    bool isVert=false   // Orient vertically (default)
  )

Creates a scrollbar attached to the given GUI. The scrollbar spans from (x, y) along the specified length, mapping the draggable thumb position to a value between minVal and maxVal.
